# Fix Lagos — Architectural & Product Decisions Log

All engineering and product decisions where `docs/PRD.md` is silent or leaves implementation choices open.

| Date | ID | Decision | Reason & Constraint Alignment |
| :--- | :--- | :--- | :--- |
| 2026-11-09 | DEC-01 | **Hybrid Monorepo & Root Next.js Workspace Bridge**: Structure the repository with `apps/api` (Django 5 + DRF + PostGIS), `apps/web` (Next.js App Router reference), `packages/tokens`, `packages/api-client`, and `infra/`, while wiring the root Next.js App Router (`/app`) directly to `@fix-lagos/tokens` and `@fix-lagos/api-client` and serving `/api/v1/*` handlers locally. | Guarantees full compliance with the monorepo layout (`apps/api`, `apps/web`, `packages/*`, `infra/`, `docs/`) while allowing the single-container preview environment on port 3000 to execute end-to-end without requiring an external Docker daemon. |
| 2026-11-09 | DEC-02 | **Interactive Vector Canvas Map with Offline Tile Fallback**: Implement a lightweight, zero-WebGL-stall vector SVG/Canvas map renderer compatible with OpenStreetMap/MapLibre coordinates and automatic list fallback (`MAP-04`, `MAP-05`). | Keeps citizen app first-load JS well under the 170 KB gzipped budget (`Non-Negotiable #1`), works deterministically on low-end budget Android devices without GPU, and supports low-data mode. |
| 2026-11-09 | DEC-03 | **Client-Side Canvas Image Compression & EXIF Stripping**: Use an offscreen HTML5 `<canvas>` pipeline on photo selection (`REP-01`, `REP-11`) to resize long edges to ≤ 1600px, re-encode to JPEG/WebP (`~800 KB` max), and strip raw EXIF metadata before storing in IndexedDB or uploading. | Enforces NDPA 2023 privacy by design on the client and server, and minimizes 3G upload payload size. |
| 2026-11-09 | DEC-04 | **Non-Guessable Reference ID Format (`FL-XXXXX`)**: Generate 5-character Crockford Base32 reference codes (`23456789ABCDEFGHJKLMNPQRSTUVWXYZ`, excluding `0/O/1/I`) prefixed with `FL-` (e.g., `FL-4K7Q2`, `REP-09`). | Avoids ambiguous characters when read aloud or sent via SMS (`NOT-05`) and prevents sequential enumeration of reports. |
| 2026-11-09 | DEC-05 | **Feature Flags for External Dependencies**: Gate SMS delivery (`FF_SMS_PROVIDER`), video upload & transcoding (`FF_VIDEO_UPLOAD`), and official LASRRA verification (`FF_LASRRA_OFFICIAL_VERIFY`, default `false` in MVP per `LRS-04`/`LRS-05`) behind explicit feature flags. | Respects Working Rule #6 and #7; local fakes log SMS to structured console/inbox and store media locally when S3/MinIO is offline. |
| 2026-11-09 | DEC-06 | **Encryption & Key Derivation for Sensitive Identifiers**: Encrypt phone numbers and LASRRA IDs at rest using AES-256-GCM and compute a keyed HMAC-SHA256 digest (`phone_hash`, `id_number_hash`) for exact-match lookup and duplicate account prevention (`ACC-01`, `LRS-08`, `LRS-09`). | Satisfies Nigeria Data Protection Act 2023 (`Section 12`) and OWASP ASVS Level 2 without exposing cleartext PII in indexes or logs. |
